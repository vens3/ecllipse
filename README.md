# Eclipse Finance — Landing Page

Landing page responsiva baseada na referência visual enviada.

## Como executar
1. Descompacte o ZIP.
2. Abra `index.html` no navegador ou use a extensão **Live Server** do VS Code.
3. A conexão com Google Fonts e GSAP é feita via CDN (necessário internet para carregar essas bibliotecas).

## Estrutura
- `index.html` — estrutura semântica e conteúdo.
- `styles.css` — identidade visual, layout e breakpoints.
- `script.js` — menu mobile e animações GSAP + ScrollTrigger.

## Personalização
Cores principais ficam no início de `styles.css`, nas variáveis CSS de `:root`.
Os mockups dos celulares foram construídos em HTML/CSS para permanecerem responsivos e editáveis.
